# Annotated page

Build `<topic>/annotated.html` as one file with inline CSS/JS and embedded figures. Optional web fonts must have local fallbacks. Use [reading extraction](../../reading/references/reading.md) for text and publication figures.

| Area | Layout |
|---|---|
| Header | Paper title/authors/venue/year and colour legend; fixed 60 px header |
| Section navigation | One jump per paper section, current section highlighted; sticky below header |
| Paragraph row | Original English and translation on the left; aligned explanation card on the right |
| Figure/table row | At first discussion; bilingual caption and evidence explanation |
| Overview | Problem, central claim, evidence chain, limits and conclusion |

Use sufficient top padding so bars do not cover content. At widths below 1024 px, use one column with collapsible cards beneath their paragraph.

| Highlight | Meaning |
|---|---|
| Yellow `#fff3b0` | Claim |
| Red `#ffd6d6` | First-use concept |
| Blue `#d6e5ff` | Evidence or number |
| Green `#d6f5d6` | Limitation or concession |
| Purple `#e8d6ff` | Method |

Highlight phrases, not whole paragraphs. Translate faithfully in natural Taiwanese Traditional Chinese; keep exact English and page numbers. Each short card gives the paragraph's purpose, connection to neighbours and anything needed to understand it; add a justified writing/logic observation only when useful.

Use the paper's `fig<N>-real.*` figures, not page screenshots. Rebuild tables from extracted text, marking unclear cells. Explain equation symbols in their card. Label general background and reader inferences separately from author claims.

Keep the existing restrained palette: navy header `#1a2744`, page `#faf8f4`, translation `#f0ece2`, card `#f5f5f5`; serif English, sans-serif interface with Chinese fallbacks. Optional questions, flip cards or concept maps are added only on request.

Before delivery, compare paragraph counts/section headings with the main paper; verify every figure and table appears once. Open the page and check bar clearance, alignment, navigation and the one-column layout. Report any gap and the reading log, then link and open the page.
