# Other requested tasks

Use only the mode the user requests; do not turn a draft review or code search into a full website build.

| Task | Do | Deliver |
|---|---|---|
| Discussion review | Check explanation, literature comparison, significance, limitations and next research; distinguish evidenced reasons from hypotheses | Specific gaps and suggested corrections; rewrite only if asked |
| Code search | Check paper/arXiv/OpenReview, conference, author/lab, then GitHub and relevant lists | Repository link, official status, last update and requested metadata; 未找到 or 尚未確認 when appropriate |
| Experiment reproduction | Load sourced data and splits, run required code/model/weights, compare under compatible conditions, retain failures | Input → computation → results → comparison, actual execution status and missing resources |

Reproduction uses paper-reading:presentation where applicable. A toy computation or passing health check does not establish reproduction of the paper's experiment.
